# homebrew-tap

Tap [Homebrew](https://brew.sh) personnel de [@jherduin](https://github.com/jherduin).

## Casks

### ClawdNotch

Indicateur visuel du notch macOS pour l'état de Claude Code en temps réel —
[dépôt source](https://github.com/jherduin/ClawdNotch).

```sh
brew install --cask jherduin/tap/clawdnotch
```

> ClawdNotch n'est pas notarisée : au premier lancement, Gatekeeper peut la bloquer.
> Clic droit sur l'app → **Ouvrir**, ou
> `xattr -dr com.apple.quarantine "/Applications/ClawdNotch.app"`.
